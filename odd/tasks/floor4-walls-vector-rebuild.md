# Floor 4 walls rebuilt from PDF vectors

Objective: rebuild every wall, column, window band and partition of `plano_oficina.pdf` in 3D from the PDF vector linework, with Peruvian-norm heights, and view it in Three.js.
Branch: `feature/floor4-meeting-room-south` (no commits without user request). Test runner: `node scripts/check-floor4-plan.mjs`, `node scripts/check-floor4-walls.mjs`, `npm run check`.

## Specs
- S1 — User request (verbatim, L1): “Siento que el model 3d en blender difire al plano, para es autoriza una revision y validacion investigando primero lectura de planos de oficina y levantar corretamente los muros y ventanas, usar la norma tecnica peruana para muros con ventanas , altura, y detalles. Lo importante es ahora mismo levantar todos los muros y tabiqueria para tener el espacio 3d y verlo en threejs”
- S2 — Research plan-reading conventions and Peruvian norms (RNE A.010/A.080/E.070) for wall, window, door heights and details; record sources.
- S3 — Model all cut concrete/masonry walls and columns as extruded polygons from the PDF outlines (width-0.72 strokes), full clear height.
- S4 — Model façade window bands (thin parallel-line bands between concrete pieces) with sill parapet, glazing and lintel at norm-based heights.
- S5 — Model all partitions (width-0.6 strokes) at their PDF positions, keeping user-validated extents, exclusions, partial heights and doors; add door lintels per norm.
- S6 — Export a new GLB and view it in the existing Three.js app.
